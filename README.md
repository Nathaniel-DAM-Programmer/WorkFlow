# WorkFlow
Proyecto simple en el que porteo una aplicacion web a apk con Node.js y Capacitor.
Se trata de una lista de tareas que puedes asignarle una prioridad, lugar y fecha. Envía un recordatorio cuando quedan 3 horas o cuando quedan 3 minutos.
# Uso IA
Me he apoyado en Gemini 3 para hacer el port de la aplicación y aprender sobre este entorno.
